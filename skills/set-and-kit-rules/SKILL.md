---
name: set-and-kit-rules
description: Goods put up in sets for retail sale and multi-component kits.
triggers: [set, kit, bundle, combo, includes]
---
For retail sets of different articles, classify by the component giving the essential character (GRI 3(b)).
Accessories sold with the main item (a charger with a phone) normally follow the main item.
Do not split a set unless components are clearly separate commercial goods.
